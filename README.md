# 博弈大师 GameMaster

> 融合强化学习与博弈论的六边形攻防策略小游戏

## 概述

博弈大师是一款面向微信小游戏平台的轻量级策略游戏，核心特色是将学术研究中的**强化学习（RL）**、**多样化策略**、**攻防博弈**和**泛化性能**概念融入游戏机制，打造与市场上同类产品差异化的体验。

## 核心特色

- **自适应 AI 对手**：AI 会学习你的策略偏好并生成反制策略，难度动态调整
- **策略多样性奖励**：使用更多元化的策略组合获得更高评分，打破唯一最优解
- **六边形攻防博弈**：在程序化生成的地图上进行回合制攻防对战
- **泛化挑战**：每局地图随机生成，规则可能变异，考验策略的适应性

## 游戏操作

1. **部署阶段**：从右侧面板选择单位类型，点击上方区域（前 4 行）放置
2. **行动阶段**：点击己方单位选中，蓝色区域可移动，红色区域可攻击
3. **结束回合**：点击「结束回合」按钮，AI 将执行操作
4. **胜利条件**：消灭所有敌方单位，或 20 回合后比较总分

## 单位克制

```
突击兵 →(克制)→ 盾卫兵 →(克制)→ 狙击手 →(克制)→ 突击兵
```
