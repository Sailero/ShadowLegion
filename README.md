# Shadow Legion / 影之军团

一款“亲自上阵守核心”的俯视角肉鸽防线游戏。玩家需要在固定进攻路线、掩体和地图机制之间移动、瞄准、闪避、拉仇恨与斩首高价值目标；核心攻防是主体，成长系统服务于兵种打法。

## 当前 Demo

- 4 章 × 5 波战役：林海、沙漠、海港、城市各有独立路线、掩体和地图机制。
- 4 个逐章解锁兵种：游骑先锋、重炮兵、壁垒卫士、蜂群工程师。
- 4 个主动技能与兵种专精卡池；波间三选一、章间大战利品、三次专精后超限进化。
- 8 种职责敌军：基础、侧翼、远程、重甲、突进、召唤、爆破、治疗。
- 双失败条件：先锋阵亡或防线失守；敌军可被玩家近身拉走仇恨。
- Boss 具备独立血条、弹幕、召唤和与实际碰撞一致的填充式冲锋预警。
- 逐章解锁下一地图、兵种与技能；另有影核工坊、排行榜、行为档案和无尽演练。

当前是完成度较高的玩法 Demo，程序化几何图形仍是占位美术，尚未经过外部玩家盲测或商业验证。

## 直接试玩

Windows 用户双击以下文件即可开始，无需安装：

```text
release/Shadow-Legion-1.1.0-Portable.exe
```

F11 可切换全屏。若 Windows SmartScreen 提示未知发布者，这是因为当前测试包未购买代码签名证书。

## 开发与打包

```bash
npm install
npm run dev
npm run build
npm run desktop
npm run package:win
```

- `npm run dev`：浏览器开发版。
- `npm run build`：TypeScript 检查与 Vite 生产构建。
- `npm run desktop`：构建后在 Electron 桌面窗口试玩。
- `npm run package:win`：生成 Windows x64 便携 EXE。

## PC 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD |
| 瞄准并持续射击 | 按住鼠标左键 |
| 闪避 | Shift 或鼠标右键 |
| 释放兵种技能 | Space（能量充满后） |
| 切换已解锁技能 | Q |
| 选择升级 | 1 / 2 / 3 或鼠标 |
| 暂停 | Esc |
| 全屏（桌面版） | F11 |

## 技术与验证

- Phaser 3 + TypeScript + Vite + Electron
- 数据自动测试：23 项
- 场景自动测试：30 项
- 开发版持续监控对象池、敌人数、数值与物理状态
- 已用真实浏览器回归新档、解锁、章间衔接、四图、四兵种、基地碰撞和最终 Boss 预警

开发版调试键：F8/K 清除当前敌人、F7/C 充满技能、F6/N 完成章节、B 跳到 Boss。生产版不包含这些调试入口。
