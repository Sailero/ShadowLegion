# Shadow Legion / 影之军团

一款正在验证中的俯视角动作生存游戏。当前版本先用经典战斗、局内构筑、Boss、轻量局外成长构成完整闭环；下一阶段验证“每局都在塑造一个像你的影子，它会陪你战斗，也能异步代表你挑战别人”是否真有辨识度和复玩价值。

## 当前可玩版本

- 一局 8 波：从基础接触、侧翼与远程压制，逐步进入混编战，最终摧毁“军团核心”。
- 3 条明确构筑：爆裂、弹幕、时隙；首波后选择协议，三次流派强化会触发一次“超限进化”。
- 6 种职责敌人：追击、侧翼、远程、重甲、猎杀、召唤；包含精英和独立 Boss 血条。
- 完整流程：单屏教程、波次提示、危险预警、暂停、死亡/胜利结算、排行榜、快速重开和无尽演练。
- 跨局闭环：战斗回收“影核”，军团工坊提供有上限的小幅强化；结算生成可解释的影子行为档案并记录三协议首通。
- 手感反馈：闪避无敌帧、拖影、击退、暴击/伤害数字、粒子、屏幕震动、程序化音效和首领冲锋预警线。

这是第一阶段的“可盲测候选版”，不是已经通过市场验证的成品。尚需 10–20 名非开发者完成平衡、理解度和重开意愿测试。

## 运行

```bash
npm install
npm run dev
npm run build
```

## PC 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD |
| 瞄准并持续射击 | 按住鼠标左键 |
| 闪避 | Shift |
| 主动技能 | Space（能量充满后） |
| 切换已解锁技能 | Q |
| 选择升级 | 1 / 2 / 3 或鼠标 |
| 暂停 | Esc |

## 技术与验证

- Phaser 3 + TypeScript + Vite
- `npm run build` 同时执行 TypeScript 检查和生产构建
- 开发环境运行时测试：数据 21/21、场景 29/29
- 开发环境调试键：F8 清除本波敌人、F7 充满技能、F6 直接验收胜利流程
