# 暖影同行：旅行绘本美术方向

本轮以玩家提出的“原画风仍不好看”为重新设计的起点。核心视觉改为狐狸旅人与薄荷色影狐的送信旅程；保留温暖、轻松和可读的动作体验。

参考来自作品官方公开画面，未复制任何第三方游戏素材：

- [Spiritfarer 官方作品页](https://thunderlotusgames.com/games/spiritfarer/)：观察大面积场景、层次清楚的环境与角色剪影。用于本作的推导是让首页首先呈现一处值得出发的地方。
- [Cozy Grove 官方作品页](https://cozygrovegame.com/)：观察自然色、明确轮廓和小角色与环境之间的尺度关系。用于本作的推导是把敌人职责放进外形，同时保留友善的气质。
- [Chicory 作者的项目页](https://gl326.github.io/paintdog/)：参考绘本表达与角色个性，采用可辨认的原创旅人，而不是抽象的几何人形。

实际资产位于 `src/public/art/`：`journey-keyart.jpg` 为全幅场景；`garden-atlas.png` 包含狐狸、影狐、八种来客、营地与树；`terrain-atlas.jpg` 包含五种地面与纸纹。均由内置 image_gen 生成，完整提示词与用途保存在 [资产生成清单](art-generation-manifest.json)。不透明原始 PNG 位于 `art/source/`，交付图经 `scripts/encode-art.cjs` 保持尺寸转换为 JPEG 92，透明角色图仍为 PNG。源图随项目保存；没有运行时生成图像或外部图片链接。

战斗中的树对应真实掩体，地形效果仍由明确的填色和边线表示。地面降低对比度，角色采用直立朝向与轻微步态，鼠标瞄准独立于身体朝向。狐狸/影狐的配色跨首页、行囊、战场和结算保持一致。特效以花火、纸片、轻跃和茶会表达，避免全屏强闪。

美观需要在实际画面中验收。静态原画通过不等于战斗画面通过；还要检查文字是否遮挡主体、缩放后可读性、透明图边缘、角色与地面的对比，以及高密度特效下的危险提示。
