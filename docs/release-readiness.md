## 静态部署交接

构建输出 `dist/`，或使用带版本的 `release/*-web-*` 目录。上传目录内容后首页为 `index.html`。`base: './'` 支持静态子目录；确认 JavaScript MIME 为 `text/javascript` 或 `application/javascript`。发布包必须通过 HTTP(S) 提供，直接双击 HTML 不是浏览器发行方式。

正式站点设置：HTML `Cache-Control: no-cache`，带哈希资产 `public, max-age=31536000, immutable`，开启 gzip/Brotli。保留上一版完整目录以供原子回滚，避免新旧 HTML/脚本交叉。Vite 官方说明 `preview` 只供本地预览，正式静态站点无需运行 Vite 服务。[Vite 部署说明](https://vite.dev/guide/static-deploy)

本地存档属于 origin。HTTP/HTTPS、不同域名、不同端口的存档互不相同；浏览器禁止持久化也可能抛异常。迁移前应提供导出途径，并在产品内表明“本机保存”，不能称为云存档。[MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)

本候选版提供试玩记录 JSON 导出，尚未提供玩家进度跨域导入。首次正式站点需固定 origin；若安排已有玩家迁站，需先完成进度迁移工具与回归。

本地生产服务补充验证：`http://127.0.0.1:4173/` 的 HTML 与实际引用脚本均返回 HTTP 200，UTF-8 页面标题与声明正确，脚本 MIME 为 `text/javascript`。这是 HTTP 资源检查，不是浏览器渲染验收。便于交付的压缩副本为 `release/Sunlit-Echoes-1.2.0-rc.1-web.zip`（401,797 字节），SHA-256：`BAC2590999F79B6DB005BB1FDE7EFC7DB56FFDA315B19BC497510219A12CBF8C`。

页面切后台会影响计时器和动画调度，须显式处理可见性，不只指望碰巧冻结帧循环。[MDN Page Visibility](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)
