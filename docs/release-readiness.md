## 可复现命令

需要 Node.js ≥22.15，推荐 Node 24；锁文件随源码提交。测试读取实际 TypeScript 逻辑；少数实体方法测试以局部 Phaser 数学 / Sprite 边界隔离模块，不模拟浏览器渲染或完整物理世界。

```bash
npm ci --ignore-scripts
npm test
npm run typecheck
npm run analyze:pacing
npm run check
npm run check:security
npm run release:web
npm run preview -- --host 127.0.0.1
```

`--ignore-scripts` 适合纯浏览器构建，无需下载 Electron。`release:web` 统一执行测试、类型 / 生产构建、静态检查和依赖审计，然后生成新的时间戳目录，附部署说明、第三方许可证与 SHA-256 清单，不上传外部服务。

Windows 标准 ZIP 打包在发布目录验证后执行，参数必须换成真实目录：

```powershell
.\scripts\package-web-release.ps1 -ReleaseDirectory ".\release\shadow-legion-web-1.3.0-rc.2-<timestamp>"
```

脚本要求目录内有 `release-manifest.json`，使用 .NET Compression 写入标准正斜杠路径，并把清单本身一并归档。它先核对所有源文件，随后重新打开 ZIP、逐项验证解压内容的大小和 SHA-256，再将校验成功的临时包移到同一父目录中的 `Sunlit-Echoes-<version>-web.zip`。额外 / 缺失文件、危险路径、符号链接、清单哈希不符和已有同名 ZIP 均被拒绝；不会删除发布目录或覆盖旧包。控制台 JSON 返回最终字节数、SHA-256 和已验证条目数。脚本已通过正常 / 异常用例，并用于上述 rc.2 正式 ZIP；重复执行同一版本会拒绝覆盖现有包。

图形烟测使用仓库脚本 `scripts/native-smoke.cjs`，在本机开发服务启动后运行：

```bash
npm run prepare:electron
npx electron scripts/native-smoke.cjs
```

默认使用 `http://127.0.0.1:3000/?renderqa=1`，可用 `SUNLIT_QA_URL` 指定本机地址。脚本为 Electron 单独设置 `.cache/render-qa-*/profile` 目录，关闭 Node 页面集成，启用上下文隔离与沙箱，通过 `capturePage` 记录真实图像；不会连接或读取用户 Chrome / Edge 等浏览器的档案。`.cache/` 中临时档案不是发布内容，也不应提交。

备份与视口检查需要已构建的 `dist` 在本机 `4173` 端口提供生产页面。在独立终端运行 `npm run preview -- --host 127.0.0.1 --port 4173`，然后执行：

```bash
node --import ./scripts/test-loader.mjs scripts/create-backup-fixture.mjs
npx electron scripts/backup-smoke.cjs
npx electron scripts/viewport-smoke.cjs
```

备份脚本生成自己的测试进度，使用临时档案与真实 File / 下载 API；不读取玩家的文件。视口脚本默认覆盖 DPR 1 的 1280×720、1366×768、1920×1080，可用 `SUNLIT_VIEWPORT_WIDTHS` 缩小范围，`SUNLIT_VIEWPORT_MODE=focus` 只查菜单 / 设置。`SUNLIT_VIEWPORT_DPR=1.5` 使用 CDP 设备指标仿真，不能被登记为 Windows 原生 150% 系统缩放。

正式持续运行脚本需要独立开发服务 `npm run dev -- --host 127.0.0.1 --port 3000`；在新的 PowerShell 终端显式设置地址与时间，避免继承生产检查参数：

```powershell
$env:SUNLIT_QA_URL = 'http://127.0.0.1:3000/?renderqa=1'
$env:SUNLIT_SOAK_MINUTES = '20'
npx electron scripts/soak-smoke.cjs
```

脚本实时运行离屏 Chromium，采样帧间隔、对象与内存，并记录场景重开和结束边界。自动控制器辅助瞄准 / 选卡、使用合法封顶构筑、补充英雄与营地生命；没有加速战斗时钟。小于二十分钟会被报告明确标为诊断，不计正式持续运行通过。运行途中不能修改源码，完成后须检查完整报告、错误、实际战斗阶段和哈希，不能仅凭进程退出或仍在刷新帧数作结论。

同一本机 `3000` 开发服务还可运行 `npx electron scripts/campaign-flow.cjs` 重现五十关加速流程，或 `npx electron scripts/ending-smoke.cjs` 重现影子纪录拒写与钱包独立保存。这些故障注入仅发生在各脚本自己的临时档案，不作用于玩家存档。

## 静态部署交接

浏览器输出为 `dist/` 或最终 `release/*-web-*` 静态目录，首页 `index.html`。必须使用 HTTP(S)，不能双击 HTML；相对资源地址支持静态子目录。确认 JS MIME、HTML 不强缓存、带哈希资源长缓存及 gzip / Brotli。保留上一版完整目录供回滚，避免新旧 HTML 与脚本混用。Vite `preview` 仅用于本地预览。[Vite 静态部署说明](https://vite.dev/guide/static-deploy)

本地存档按 origin 隔离：不同协议、域名和端口不共享。[MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) rc.2 已提供完整旅途 JSON 备份 / 恢复，迁移设备或站点前应先在旧站点下载备份，再在新站点营地设置中读取文件、核对通关 / 星章 / 暖晶并确认恢复。八类数据涵盖永久成长、路线、起点续玩、设置、排行榜、影子纪录、教程状态和本地波次样本；不上传服务器，也不创建云账号。未来版本或坏数据会拒绝，写入失败会提示并尽可能回滚。正式站点仍应固定 origin，目标浏览器的完整文件选择 / 下载与写入失败体验需要验证。
