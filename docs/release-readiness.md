## Alpha 到 Steam 成品的三个未完成门槛

1. **内容与时长**：五片可往返送信区域、人物回应、操作/影伴挑战、可选发现与完整结尾尚未制作完成。目前只有第一封森林信的操作循环；其 3–5 分钟是设计目标，三小时同样未经真人测得。旧战役约 38 / 52 / 94 活跃分钟是不同假设下的理论模型，不能补算成三小时冒险。[内容预算与参考边界](steam-three-hour-plan.md)
2. **PC 操作与桌面持久化**：手柄全流程、按键重绑、设备提示切换、受限主进程文件存档与旧 localStorage 迁移尚未完成。现有 Electron 配置和打包命令不是经过验收的 Steam 桌面发行物；需验证离线重启/升级、窗口与全屏、多显示器及 Windows 原生 DPI。Steam Deck、Steam Cloud、macOS 与 Linux 均不承诺已支持。
3. **完整体验与发行内容**：最终 alpha 的自动检查和静态包已通过上述验证，真实普通操作、参考硬件持续性能和真人盲测仍需分别留证。面向计划支持的语言补齐英文文本与字幕/可读性，完成美术、字体、音频、运行时许可与商店截图审阅，再准备 Steam 商店资料与构建审核；这些工作尚未完成。具体哪些是 Valve 流程、哪些是本作质量目标，见 [Steam PC 计划](steam-three-hour-plan.md)，不把所有项目误写为平台统一强制要求。

## 可复现命令

需要 Node.js ≥22.15，推荐 Node 24；锁文件随源码提交。测试读取实际 TypeScript 逻辑；少数实体方法测试以局部 Phaser 数学 / Sprite 边界隔离模块，不模拟浏览器渲染或完整物理世界。

```bash
npm ci --ignore-scripts
npm test
npm run typecheck
npm run analyze:pacing
npm run check
npm run check:security
npm run release:web
npm run preview -- --host 127.0.0.1
```

`--ignore-scripts` 适合纯浏览器构建，无需下载 Electron。`release:web` 统一执行测试、类型 / 生产构建、静态检查和依赖审计，然后生成新的时间戳目录，附部署说明、第三方许可证与 SHA-256 清单，不上传外部服务。

Windows 标准 ZIP 打包在发布目录验证后执行，参数必须换成真实目录：

```powershell
.\scripts\package-web-release.ps1 -ReleaseDirectory ".\release\shadow-legion-web-1.4.0-alpha.1-<timestamp>"
```

脚本要求目录内有 `release-manifest.json`，使用 .NET Compression 写入标准正斜杠路径，并把清单本身一并归档。它先核对所有源文件，随后重新打开 ZIP、逐项验证解压内容的大小和 SHA-256，再将校验成功的临时包移到同一父目录中的 `Sunlit-Echoes-<version>-web.zip`。额外 / 缺失文件、危险路径、符号链接、清单哈希不符和已有同名 ZIP 均被拒绝；不会删除发布目录或覆盖旧包。控制台 JSON 返回最终字节数、SHA-256 和已验证条目数。脚本已通过正常 / 异常用例，并用于上述 rc.2 正式 ZIP；重复执行同一版本会拒绝覆盖现有包。

图形烟测使用仓库脚本 `scripts/native-smoke.cjs`，在本机开发服务启动后运行：

```bash
npm run prepare:electron
```

## 静态部署交接

浏览器输出为 `dist/` 或最终 `release/*-web-*` 静态目录，首页 `index.html`。必须使用 HTTP(S)，不能双击 HTML；相对资源地址支持静态子目录。确认 JS MIME、HTML 不强缓存、带哈希资源长缓存及 gzip / Brotli。保留上一版完整目录供回滚，避免新旧 HTML 与脚本混用。Vite `preview` 仅用于本地预览。[Vite 静态部署说明](https://vite.dev/guide/static-deploy)

本地存档按 origin 隔离：不同协议、域名和端口不共享。[MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) 从旧站点迁移前先下载旅途 JSON 备份，再在新站点邮局设置中读取文件、核对通关 / 星章 / 暖晶及森林邮路并确认恢复。alpha 白名单共九域：永久成长、路线、起点续玩、设置、本机成绩、影子纪录、教程、本地波次样本和新增森林邮路；不上传服务器，也不创建云账号。旧八域备份缺少邮路项时保留本机邮路，恢复预览会列出保留项目；明确的空值按预览清除对应域。未来版本或坏数据会拒绝，写入失败会提示并尽可能回滚。正式站点仍应固定 origin，目标浏览器完整文件选择 / 下载与新增域往返仍需验收。此浏览器备份不等于已完成 Steam 离线文件存档或升级迁移。
