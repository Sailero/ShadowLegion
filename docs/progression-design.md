# 暖影同行：旅人行囊与角色专精

本轮把 50 个独立小关卡、工坊消费、角色熟练度、影子对战、无尽挑战接入同一个本地成长体系。它的长期吸引力是学会新的防守方式、选择不同的旅行准备，并让不同伙伴完成自己的路线。

## 研究依据与采用方式

Supergiant 的《Hades》官方介绍同时强调局内多种祝福构筑、Mirror of Night 永久成长，以及玩家可以主动提高挑战。本项目据此把局内升级、有限基础支持、额外挑战分开：基础工坊解决容错，角色专精改变走位和火力选择，影子与无尽提供后续挑战。这里借鉴的是结构，具体成本和解锁关数均为本项目设计。[开发商官方商店介绍](https://store.steampowered.com/app/1145360/Hades/)

Cellar Door Games 的《Rogue Legacy 2》官方介绍将永久庄园成长、不同职业打法、改变玩法的能力和带有代价的遗物并列。我们采用可看懂的取舍与职业差异，让“买了一个选项”能改变实际战斗；专精不会全部同时叠加。[开发商官方商店介绍](https://store.steampowered.com/app/1253920/Rogue_Legacy_2/)

这些资料没有提供适用于本游戏的实测成长时长。下列节奏是关卡数和经济预算设计，仍需真人试玩验证理解成本、挫败点与选择分布。画风遵循温暖的旅行绘本：名字采用口袋、茶园、抱枕、弹珠等日常事物，描述明确保留优点和代价。

## 四名伙伴的十二种专精

同一行的三项价格依次为 8、12、16 暖晶；熟练度要求依次为 2、4、6。购买与选用分开，已购选项免费重新配置，默认可以不装备。

| 伙伴 | 专精一 | 专精二 | 专精三 |
| --- | --- | --- | --- |
| 花火游侠 | 追风漫游：移动 +10%，伤害 −8% | 满园花火：爆炸等级 +1，冲刺冷却 +15% | 会心一笑：暴击率 +12%，攻速 −10% |
| 爆米花炮手 | 穿针引线：弹丸穿透，伤害 −10% | 加一份爆米花：攻速 +15%，移动 −10% | 边走边聊：移动 +12%，攻速 −10% |
| 抱抱守卫 | 抱枕堡垒：开局护盾 +2，伤害 −8% | 慢慢喝口茶：每秒恢复 2 生命，攻速 −10% | 及时小雨伞：冲刺冷却 −18%，最大生命 −15 |
| 蜜蜂工匠 | 回声弹珠：弹射等级 +1，伤害 −10% | 灵感叮咚：每次击败敌人多 2 灵感，攻速 −8% | 小小维修窝：护盾 +1、每秒恢复 1，移动 −8% |

角色熟练度总阈值为 0、12、30、60、100、150、220，共七级，达到 220 后停止增加。各角色独立记录。该角色第一次完成某关获得 `4 + 2 × 星数` 熟练度；以后只在该角色提高这关最高星数时，每颗新星再获得 2。反复打同一成绩不加熟练度。

因此第一套专精在两次不同关卡的一星通关后即可解锁；第三套专精需要该角色累计十五次不同关卡三星，或二十五次不同关卡一星。满熟练度需要二十二次三星或三十七次一星。该数字描述成功通关数量，不是预计分钟数。

## 单钱包奖励与经济预算

| 来源 | 暖晶规则 | 熟练度规则 |
| --- | --- | --- |
| 某关首次通关 | `3 + 星数`，全档案仅一次 | 按该角色在该关的首次 / 提星计算 |
| 关卡最高星数提高 | 每颗新星 +1 | 该角色最高星数每提高一颗 +2 |
| 没有提高最高星数的重复通关 | 每次 +1，同一关终身最多三次 | 已取得同成绩的角色 +0 |
| 影子五阶 | 新阶首次分别 6、8、10、12、14，总计 50 | 每角色新阶分别 12、14、16、18、20 |
| 无尽纪录 | 每新增五波纪录 +2，最多前一百波，共 40 | 每角色每五波新纪录 +3，同样最多前一百波 |
| 失败 | 不另发通关 / 镜像奖励 | 不另发完成熟练度 |

影子与无尽的门槛由各模式的流程控制；Meta 根据经过验证的完成结果维护永久最高进度。同一个角色重复刷旧影子阶与旧无尽纪录不会继续增加暖晶或熟练度。若前次钱包保存失败，后续更高模式纪录可以补回缺失的前序里程碑奖励。

完成五十关一星共获得 200 暖晶。基础装备 60 + 全部研究 68 + 一名角色三专精 36 = 164，仍剩 36。全部十二专精连同装备、研究共 272；五十关三星的首次 / 提星总奖励为 300。重玩和额外模式可以提供补充，但基础成长预算不要求反复刷同一简单关。

角色构筑全通成就要求该角色确实完成全部五十关，可以最后补完任何一关触发。只用新角色完成第五十关，不会借用其他角色的路线成绩。单关时间不会写入旧版全战役最快用时。

## 保存、接口与验证

数据定义位于 `src/data/progression.ts`，读写与战斗应用在 `src/systems/MetaProgressionManager.ts`。保留旧 localStorage 键 `shadowlegion_meta_v1`，内容版本升级到 3。旧版暖晶、装备等级、已获角色、技能与统计保留；已经完成的旧章节对应十个关卡的一星路线访问权限，标记为迁移记录，不追溯发首通暖晶。

`recordStageProgress` 是战役唯一发奖入口；CampaignProgressionManager 负责关卡访问和成绩，Meta 同一份写入内保存暖晶、熟练度、最高星、领取凭据。独立路线与钱包写入可能分别失败，重复完成事件允许补写此前没有保存的一边。`recordModeProgress` 处理影子 / 无尽；`recordRun({recordOnly:true,...})` 仅记录档案统计，不重复发奖。传入独立 `stageId`、影子 / 无尽 mode，或 `endless:true` 也会自动阻止旧奖励路径。

近期事件凭据最多 2048 项；每关最多六次会产生暖晶的完成凭据永久保存，首通 / 提星 / 重玩次数和每角色最佳星数另有永久记录，因此旧的付费奖励事件离开近期窗口后仍不能再次领取。模式奖励由永久最高纪录去重。所有奖励有有限上限，存档中的数字、ID、星数、角色装备关系均经过净化；无法写入时购买返回 false，不展示虚假的扣款成功或奖励。未来版本的存档不会被旧客户端覆盖。

`getResearchNodes` / `getSpecializations` / `getMastery` / `getProgressionOverview` 提供工坊展示数据；`purchaseResearch` / `purchaseSpecialization` / `equipSpecialization` 直接消费与保存。战斗创建 Hero 后，先初始化角色，再调用一次 `applyCombatBonuses(hero, operativeId)`；该函数已经包含旧基础装备效果。返回的 `coreHpBonus` 由 Arena 加到营地耐久。所有倍率和加法通过真实 Hero 字段生效。

自动测试：`node --import ./scripts/test-loader.mjs --test src/test/progression.test.mjs`。覆盖消费门槛、互斥专精、全部十二种战斗效果、首通 / 提星 / 重玩上限、独立角色熟练度、旧存档迁移、非法数据、写入失败、模式奖励恢复、存档未来版本保护、角色全通成就与经济总预算。自动逻辑测试不能替代五十关真人体验、专精强弱分布或低配置机器运行验证。
