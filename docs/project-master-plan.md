# Shadow Legion / 影之军团：项目总纲

> 文档性质：项目唯一产品事实源。当前实现、产品定位、平衡基线与后续路线都以本文件为准。
>
> 当前阶段：四章攻防战役 Demo 已完成，进入外部盲测与内容验证阶段。
>
> 更新日期：2026-08-27

## 0. 结论先行

项目已经从“单张地图的 360° 生存射击”调整为：

> **玩家亲自上阵的移动防线 × 固定进攻路线的攻防博弈 × 兵种专属能力 × 逐章解锁的 Roguelite 战役。**

玩家既不是站桩炮塔，也不是只顾自己生存的割草角色。玩家要在有限路线、掩体和地图机制之间移动，决定拉走哪一股仇恨、先处理哪种敌军、何时守核心、何时离线斩首。这是当前版本最需要验证的差异化。

玩法注意力重新分配为：

| 层级 | 占比目标 | 内容 |
|---|---:|---|
| 核心攻防 | 70% | 移动、瞄准、闪避、拦截路线、守核心、目标优先级、兵种能力、Boss 读招、地图反制 |
| 单局与跨局成长 | 20% | 三选一改装、章间战利品、兵种/技能/章节解锁、工坊 |
| 身份与长期扩展 | 10% | 战绩、行为档案、挑战规则；影子/异步玩法只有核心攻防成立后才继续 |

过去“战术系统只占少量玩法、以后再靠 AI 形成卖点”的顺序已经否决。现在所有主要内容必须回到攻防核心：兵种改变守线方式，地图改变站位和路线，升级强化兵种身份，敌军组合制造目标优先级，Boss 检验预警识别与路线利用。

## 1. 借鉴对象与边界

本轮只借鉴成熟产品的结构原则，不复制角色、数值、关卡、美术、文案或商业包装。

- 《向僵尸开炮》的公开产品信息强调射击 Roguelike、随机技能组合、丰富地图/怪物、佣兵与基地成长。可借鉴的是“防线目标 + 局内组合 + 局外解锁”的循环，而不是做成自动站桩复刻。[TapTap 产品页](https://www.taptap.cn/app/583688)
- 4399《僵尸防线》的核心描述是指挥战士建立防线、处理换弹并阻止敌人突破。可借鉴的是清晰进攻方向和防线压力，而不是恢复成纯塔防。[4399 游戏页](https://h.4399.com/zzy/250029.htm)
- 《肉鸽防线》的公开描述包含英雄/特质选择、城堡升级、资源管理和研究解锁能力。可借鉴的是“选择扩展而非纯数值膨胀”的成长方式。[Steam 产品页](https://store.steampowered.com/app/3427090?l=schinese)

由此形成四条设计约束：

1. 敌人不能再无规律地从四面八方贴脸刷新；每张图必须有 2–4 条可提前阅读的进攻路线。
2. 玩家必须能离开核心主动截击，因此不能退化为自动炮台或只看技能动画。
3. Roguelite 选择必须强化兵种打法，不能重新变成和角色身份无关的“战术协议”。
4. 地图机制要能同时影响玩家与敌军，允许玩家借地形反制，而不只是换背景颜色。

## 2. 当前可玩 Demo

### 2.1 完整流程

```text
菜单 / 工坊
→ 行动编队：选择已解锁兵种与起始章节
→ 每章 5 波固定路线攻防
→ 每波结束三选一战地改装
→ 同兵种专精累计 3 次触发超限进化
→ 第 5 波地图 Boss
→ 章节结算、恢复、三选一章节战利品
→ 解锁下一章、下一兵种与支援技能
→ 四章完成后战役胜利结算
```

失败有两种清晰原因：先锋阵亡或防线失守。两者都会进入结算并保留可获得的影核；章节首通解锁即时写入本地存档。

### 2.2 四章地图与特色

| 章 | 地图 | 路线 | 地图机制 | 本章战斗问题 |
|---|---|---:|---|---|
| 1 | 林海前哨 | 南北 2 路 | 古木掩体阻挡双方子弹 | 学会拉仇恨、截击和利用掩体 |
| 2 | 赤砂遗迹 | 东西 3 口 | 流沙使玩家减速 24%、敌军减速 12% | 把重甲引入流沙，并切入远程阵地 |
| 3 | 沉潮港湾 | 三座栈桥 | 左右水道每 5 秒交替涨潮并减速 | 预判安全通道，避免三桥同时堵塞 |
| 4 | 霓虹围城 | 四个街口 | 电轨先预警后爆发，伤害轨道内敌我 | 用环境伤害反制完整敌军混编 |

地图均包含独立配色、掩体碰撞、子弹遮挡、固定出生口、危险区表现和小地图信息。无尽模式按四图循环，并随轮次提高强度。

### 2.3 四个兵种不再是“换皮战术”

| 解锁 | 兵种 | 开局能力 | 专属技能 | 构筑身份 |
|---|---|---|---|---|
| 初始 | 游骑先锋 | 暴击 +8%、闪避冷却 -15%、命中爆炸 | 能量爆发 | 机动截击与爆炸连锁 |
| 过第 1 章 | 重炮兵 | 双弹道、攻速 +10%、移速 -8% | 弹幕风暴 | 多弹道持续压制 |
| 过第 2 章 | 壁垒卫士 | 生命 +35、初始护盾 2 层、射速 -8% | 时空裂隙 | 护盾、迟滞与守线控制 |
| 过第 3 章 | 蜂群工程师 | 追踪弹、弹射 1 次、基础伤害 -8% | 蜂群哨戒 | 部署、追踪与弹射支援 |

每个兵种拥有自己的专精卡池与超限进化。已永久解锁的其他技能会以“支援蓝图”进入局内卡池，因此同一兵种可以出现不同副技能组合，但其主身份不会被稀释。

蜂群哨戒已经实现为实际部署物：自动寻找目标并射击，升级后提高伤害、范围、持续时间并获得穿透。它不是仅修改一项数值的占位按钮。

### 2.4 Roguelite 成长

局内成长分两层：

- **波间改装：** 每波从兵种专精、通用生存/火力和已解锁支援技能中选择三张；卡池会过滤满层、无前置技能和不属于当前兵种的卡。
- **章间战利品：** 六类大强化，包括老兵火控、防线共振、跨区机动、战区电池、火力迭代与全线维修；效果带入后续章节。

跨局成长也分为两类：

- **扩展选择：** 逐章解锁章节、兵种和技能，是主要长期动力。
- **有上限数值：** 工坊三项各 5 级，最终上限为伤害 +15%、生命 +25、初始能量 +40，不能替代操作和构筑。

旧存档会迁移到 v2，并按最高已解锁章节补齐已经挣得的兵种/技能，不会因版本升级丢失进度。

### 2.5 八种敌军职责

| 敌军 | 主要职责 | 反制重点 |
|---|---|---|
| 史莱姆 | 基础数量压力 | 快速清理、积累能量 |
| 蝙蝠 | 高速侧翼 | 保持移动、避免漏过防线 |
| 弓箭手 | 远程阵地 | 主动切后排或用掩体断弹道 |
| 重甲 | 慢速破线 | 引入减速区，避免其接触核心 |
| 忍者 | 高速突进/飞镖 | 保留闪避，读取突进节奏 |
| 召唤师 | 远程压制/增援 | 优先斩首，防止数量失控 |
| 爆破兵 | 圆形范围爆炸 | 红圈 720ms 内离开或快速击杀 |
| 修复师 | 范围治疗 | 青色治疗脉冲出现时立即集火 |

敌军默认以防线核心为目标；当先锋进入约 165 距离（Boss 约 240）时会被主动拉走。这使“离线截击”和“回防保核”成为真实决策，而不只是背景叙事。

### 2.6 Boss 预警与能力调试结果

Boss 冲锋使用同一份可测试参数：

- 预警 900ms；
- 冲锋持续 650ms；
- 实际伤害走廊宽 72；
- 基础冲锋速度 440，按 Boss 体型微调；
- 预警长度严格等于“速度 × 持续时间”，并显示终点圆与距离；
- 预警用半透明填充走廊表达实际命中范围，不再只有一条容易误判的红线。

Boss 同时保留环形弹幕、召唤和冲锋，但能力间存在冷却。最终章实机回归已捕捉到完整的“锁定—走廊预警—冲锋—位移结束”序列。

### 2.7 表现与可用性

当前已有：章节选择/锁定状态、兵种卡、章节首通解锁提示、防线生命条、Boss 独立血条、波次目标、准星、小地图出生口/掩体/危险区、屏幕震动、闪光、受击数字、击退、拖影、程序化音效、教程、暂停、排行榜、快速重开与无尽演练。

程序化几何美术已经能区分森林、沙漠、海港和城市，但仍属于规则验证级视觉，不应被描述为正式商业美术。

## 3. 核心玩法为什么现在占 70%

“70%”不是文案比例，而是每个系统是否反过来强化攻防决策：

| 系统 | 如何渗透核心攻防 |
|---|---|
| 章节 | 改变来敌方向、可用掩体和回防路线 |
| 地图机制 | 同时改变敌我移动或造成可利用的环境伤害 |
| 兵种 | 改变截击距离、火力覆盖、承压方式与主动技能 |
| 波间卡牌 | 强化当前兵种身份或增加副技能，不另起无关系统 |
| 敌军混编 | 通过前排、远程、爆破、治疗、召唤制造击杀顺序 |
| Boss | 把掩体、危险区、闪避和地图机制组合成终局考试 |
| 跨局解锁 | 主要增加新打法与新地图，而不是只抬伤害数字 |
| 结算 | 明确记录先锋/防线失败、兵种、章节和行为档案 |

因此，地图、兵种、肉鸽、Boss 和成长不再是五套并列功能，而是同一条“移动防线”循环的不同时间尺度。

## 4. 当前差异化定位

当前版本和几类常见产品的区别如下：

| 常见类型 | 常见重点 | Shadow Legion 的选择 |
|---|---|---|
| 纯割草生存 | 360° 敌潮、角色活着即可 | 敌人从有限路线进攻，玩家还要保护可被摧毁的核心 |
| 站桩防线 | 自动攻击/技能选择，移动很少 | 手动瞄准、移动、闪避、拉仇恨和主动斩首 |
| 传统塔防 | 放置单位后观察路线 | 玩家本身就是最重要的可移动防御单位 |
| 纯英雄射击 | 只处理自身生存与输出 | 必须在个人安全、清后排和核心血量之间权衡 |

对外可用一句话：

> **这是一款要亲自跑动、瞄准和拉仇恨的肉鸽防线游戏：每张地图都有可读路线，每个兵种都用不同方式守住同一个核心。**

影子行为档案与未来异步挑战只保留为长期身份层。它不能替代基础战斗，也不应在外部玩家尚未认可移动防线前扩大投入。

## 5. 平衡基线

### 5.1 玩家与局长目标

- 初始生命 120，基础弹伤 10，射击间隔 180ms，移动速度 180。
- 闪避持续 160ms、冷却 1000ms；受击无敌 250ms。
- 基础技能需要 100 能量，每个普通击杀充能 15。
- 单章目标时长 4–7 分钟；完整四章首次战役目标 20–30 分钟。
- 第一章首局通关率目标 55%–75%；完整战役首局通关率目标 15%–30%。

### 5.2 敌军数值意图

- 蝙蝠/忍者以速度换生命，不能同时拥有重甲级承伤。
- 重甲 150 生命、36 移速、22 接触伤害，是明确的破线单位。
- 弓箭手/召唤师/修复师保持距离，逼迫玩家离开核心，但单发伤害低于突进和爆破。
- 爆破兵 46 生命、26 爆炸伤害；可读红圈是其强度预算的一部分。
- 修复师治疗附近敌人最大生命的 24%，自身火力低，价值来自目标优先级。
- 精英乘区为生命 ×2.1、速度 ×1.2、伤害 ×1.35；Boss 不再重复叠加精英与 Boss 生命倍率。

章节强度以第一章为 1.0，之后生命倍率约为 1.12 / 1.25 / 1.38，伤害倍率约为 1.06 / 1.12 / 1.18；防线生命同步提高为 360 / 400 / 440 / 500。强度增长来自新职责和组合的权重应高于单纯数值增长。

### 5.3 兵种平衡原则

1. 每个兵种有清晰强项和可感知代价，不能成为前一个兵种的纯升级。
2. 所有兵种应能完成四章，但处理同一压力的路径不同。
3. 专属技能的高光属于玩家；自动哨戒不能长期提供超过玩家主要输出的火力。
4. 三次专精触发进化的时间应落在第 2–3 章，太早会失去成长，太晚会看不到成型。
5. 平衡以“章节通关率、核心剩余血量、升级选择率、死亡来源”共同判断，不只看 DPS。

## 6. 测试与质量现状

当前自动验证覆盖：

- 23 项数据测试：章节、波次、敌军引用、兵种、技能、卡池、存档、奖励、Boss 预警参数与平衡边界；
- 30 项场景测试：实体、生命/护盾/能量、UI、碰撞、物理与系统注册；
- 持续场景监控：时间倍率、子弹/粒子/经验对象上限、敌人数量、数值合法性；
- TypeScript 检查与 Vite 生产构建；
- 浏览器人工回归：新档编队、逐章解锁、章间战利品、四张地图、四个兵种、基地碰撞、最终 Boss 预警。

本轮浏览器回归实际发现并修复：

1. 章节战利品选择后旧战场恢复，残留敌军可在切图前杀死玩家；现已在整个切换期冻结旧战场。
2. 基地与敌军碰撞回调参数顺序错误，接触核心时会调用不存在的方法；现已固定对象顺序并实机验证。
3. 角色带护盾时通用受伤测试会误判；测试现会暂存并恢复护盾、闪避和无敌状态。
4. 已死亡场景仍可接收关卡完成事件并错误解锁章节；现在死亡后完成事件直接忽略。
5. v1 旧存档可能有章节进度但缺少对应新兵种/技能；迁移现会按进度补齐。

开发环境快捷键为 F8 清波、F7 充能、F6 完成章节；同时提供 K/C/N 字母别名与 B 直达 Boss，全部只存在于开发构建。

## 8. 下一阶段：先验证，再扩量

### G1：5 人问题发现

观察而不提示，重点记录：

- 是否在 30 秒内理解“人和核心都不能死”；
- 是否能说出来敌路线而非“还是四面八方乱刷”；
- 是否主动拉走敌军或切远程/治疗/爆破；
- 第一次地图机制伤害/减速是否可归因；
- Boss 走廊是否看懂，躲的是填充区域而非细线；
- 章节结束后是否期待新兵种/技能并愿意继续。

### G2：15–30 人方向测试

继续门槛：

| 指标 | 目标 |
|---|---:|
| 教程后能复述双失败条件 | ≥ 85% |
| 能指出至少两条进攻路线 | ≥ 80% |
| 第一章首局通关率 | 55%–75% |
| 主要死亡原因能正确归因 | ≥ 80% |
| 能说出至少两个兵种的打法差异 | ≥ 70% |
| 首通后愿意立即试新兵种/章节 | ≥ 60% |
| Boss 预警被评价为“看得懂但要反应” | ≥ 70% |

必须记录的遥测：章节/波次退出、先锋/核心死亡、敌军伤害来源、核心失血来源、每次卡牌选择、专精进化时间、技能释放、Boss 预警命中、各兵种通关率与核心剩余血量。

### G3：内容扩展条件

只有 G2 达标才扩内容：

- 为每章补 1 个可替换地图布局与 1 个精英变体，形成“同主题不同路线”；
- 每兵种补第二种签名改造分支，而不是新增第五个相似兵种；
- 增加章节事件与可选择防御设施，使玩家能临时改变路线；
- 正式美术先做一章垂直切片，验证可读性和宣传素材，再批量替换；
- 影子队友/异步挑战只以 10% 身份层做小原型，不改变 70% 核心攻防资源优先级。

## 9. 完整发行版目标

当前 Demo 已有四章主骨架。完整发行候选版还需要：

- 每章至少 3 个布局/事件组合，避免背板后失去变化；
- 每个兵种至少 2 个可见终局形态，支援技能形成可读组合；
- 10–12 种敌军职责、4 个机制不同的正式 Boss；
- 正式角色、敌军、场景、动画、音乐和分层音效；
- 设置、键位重映射、闪光/震动强度、字号与色彩辅助；
- 断点恢复、存档导入导出、崩溃记录和性能档位；
- 若转微信：触控方案、自动瞄准 A/B、生命周期、包体、低端真机与合规；
- 若做商业化：先验证留存与内容消耗，再讨论激励广告、外观或通行证。

“完整”不等于继续加系统。完成定义是核心攻防能稳定产生三类决策：去哪里守、先杀谁、何时使用兵种能力；并且四章通过地图与敌军组合持续改变这三类答案。

## 10. 主要风险与停止条件

| 风险 | 早期信号 | 应对 |
|---|---|---|
| 核心仍像普通割草 | 玩家只绕圈，不关心核心和路线 | 增强路线事件、拉仇恨反馈与失守归因；两轮无改善则重做核心 |
| 核心负担过重 | 玩家觉得同时瞄准、躲避、守点太忙 | 降低首章远程/侧翼并测试轻度自动瞄准 |
| 地图只是换色 | 玩家说不出四图机制 | 强化视觉预警和可利用收益，删除无决策价值的机制 |
| 兵种只差数值 | 玩家看不出打法差异 | 优先重做开局能力和专精卡，不继续加兵种数量 |
| Boss 看不懂 | 死亡无法归因、预警与实际范围不符 | 用同一参数生成预警和碰撞，逐帧录制验证 |
| 肉鸽卡池失控 | 总选同一张或大量废牌 | 跟踪选择率，合并弱卡，保证兵种/通用/支援结构 |
| 内容成本爆炸 | 每张图都需要定制代码 | 地图数据化，机制限制在少量可组合 Hazard 类型 |
| 元成长碾压操作 | 老玩家站桩通关 | 数值封顶，长期成长转向选择与身份 |
| 过早投入 AI/联网 | 基础战斗尚未通过盲测 | 冻结相关投入，按 70/20/10 优先级执行 |

## 12. 当前成功定义

本轮 Demo 的成功不以“代码量”或“地图数量”判断，而以玩家是否真实感到：

1. 来敌方向可读，压力来自选择而不是混乱；
2. 守住核心与先锋生存同样重要；
3. 四张地图改变了站位和路线；
4. 四个兵种改变了打法，不是简单强弱；
5. 肉鸽升级让当前兵种成型，并允许有限跨技能组合；
6. Boss 预警与实际伤害严格一致；
7. 通关一章后有明确的解锁期待和继续动力。

七项经外部玩家验证后，项目才进入正式美术和内容量产；否则继续迭代移动防线本身，不用外围功能掩盖核心问题。
