# 暖影同行 / Sunlit Echoes：项目总纲

更新：2026-09-12。当前候选版 **1.3.0-rc.1**。技术包名仍为 `shadow-legion`，旧存储键保留兼容。实现内容、自动检查和人工体验验证分别记录，发布状态以 [发行准备](release-readiness.md) 的证据为准。

## 定位与核心卖点

**在五十段温暖旅途中，借地形守住营地，选择自己的拿手打法，让昨天的战斗习惯成为今天的影伴。**

玩家同时照顾自己与营地：先读来路，再决定在哪里拦截、先处理谁、何时回防、把影伴留在哪里。固定地图与独立编排让失败后能改策略；不同角色、局内卡牌与可切换专精让同一关有不同解法。

用户要求画面温和、温暖、风趣，并区别于末日暗黑风。新视觉围绕旅行绘本、邮戳、花园、水粉纸纹、围巾小狐狸、爆米花、茶会和蜜蜂展开。实际危险区、来路、敌人职责与技能反馈仍须清晰，温暖不意味着取消操作挑战。

## 三种模式与完整循环

| 模式 | 内容结构 | 玩家目标 | 长期回报 |
| --- | --- | --- | --- |
| 旅行战役 | 五章各十个独立小关，共五十关 | 完成防守并挑战两项额外星级目标；逐关解锁、可重玩 | 首通 / 提星暖晶、固定伙伴解锁、各角色熟练度 |
| 无尽巡游 | 每站五波，地图轮转并逐步加压 | 带着构筑争取更远站点与最高波次 | 新五波里程碑奖励，前一百波有有限永久收益 |
| 影子切磋 | 五阶，每阶三轮；由单影读招到双影合奏 | 读预警、找空隙、合理分配火力；营地免受切磋伤害 | 各阶首次暖晶、最佳用时、各角色有限熟练度 |

```text
绘本首页 → 选模式 / 旅行路线 → 伙伴与行囊准备
→ 查看本关路线、任务与星级条件 → 开场选择改装
→ 走位截击 + 影伴同行 / 守营 + 技能与地形配合
→ 波间三选一，形成当关构筑 → 清空本关 / 本阶全部轮次或失败
→ 星级与任务回顾、暖晶、熟练度、行为档案保存
→ 下一封信 / 提星重玩 / 工坊购买与换专精 / 另一种模式
```

战役小关有独立名称、地图几何、来路、敌人组合和两项额外目标，不靠重复同一遭遇换编号凑数量。一般小关两波，精英 / 章末关三波；内容数据由 `src/data/stages.ts` 管理。通关获得一星，两项目标分别再给一星；失败不会获得通关星，也不会解锁下一关。

## 五章地图与任务身份

| 章 | 规则身份 | 主要决定 |
| --- | --- | --- |
| 草地旅途 | 树径掩体与南北换线；第一关从单一路线教学 | 读路线、挡弹、指挥影伴、闪避回防 |
| 杏沙小镇 | 软沙降低敌我移动速度，多路分批进入 | 引队伍过沙，绕过前排切投手与茶师 |
| 薄荷港湾 | 栈桥与交替潮汐 | 提前换路，在快敌与召唤支援之间取舍 |
| 花灯集市 | 四街混编，灯带先预警再爆发 | 借危险区处理前排，拆开治疗 / 召唤 / 远程组合 |
| 晴空溪谷 | 十字花桥与横纵交替潮水，综合前期能力 | 外侧截击、内侧守营、双向转线和支援优先级 |

每章十关采用开阔、分路、错位、走廊、环形、交叉、散岛、折线、花园和竞技场等几何安排，配合独立遭遇编排。八类基础敌人承担数量、侧翼、远程、重甲、突进、召唤、爆破、治疗职责。可爱的美术轮廓也要帮助辨认这些职责。

独立关卡目标涵盖守营血量、完成用时、闪避、技能、命中危险区内对手、影伴指挥、营地外围拦截和后排优先处理。数据测试检查目标所需地形 / 敌人确实存在；这种检查证明目标可达条件存在，不能证明任务负担、难度或用时合适。

## 局内流派与永久成长

| 伙伴 / 流派 | 打法 | 职业技能 | 新档解锁 |
| --- | --- | --- | --- |
| 花火游侠 / nova | 机动爆发、暴击与范围连锁 | 花火派对 | 初始 |
| 爆米花炮手 / storm | 多弹道、连射、穿透，移速有代价 | 爆米花雨 | 第 3 关 |
| 抱抱守卫 / rift | 生命、护盾、迟滞，射速有代价 | 慢悠悠茶会 | 第 8 关 |
| 蜜蜂工匠 / engineer | 追踪、弹射、部署，单发伤害有代价 | 蜜蜂小帮手 | 第 15 关 |

开场与波间卡牌提供流派路线、通用支持和已解锁技能；过滤重复卡、满层 / 满级和不满足前置的卡。同流派三次局内路线升级可触发进化；它与工坊里跨局装备的角色专精是两个不同系统。

永久成长是可消费、可选择且有上限的行囊：三项基础装备各五级；六项营地研究在完成 2 / 5 / 10 / 18 / 28 / 40 个不同关卡后可购买；四名伙伴各有七级熟练度、三套专精，解锁要求为熟练度 2 / 4 / 6。每名伙伴最多同时选用一套专精，购买后可免费切换或收起。十二套专精都提供实际战斗效果与代价，避免只累加永久伤害。

五十关一星奖励合计 200 暖晶；基础装备全满 60 + 全部研究 68 + 一名角色三套专精 36 = 164。全部十二专精、研究与基础装备共 272，五十关三星的首通 / 提星奖励合计 300。角色熟练度只随该角色第一次完成某关或提高该关星级增加，最高 220；重复旧成绩不继续刷熟练度。详细效果、经济预算和官方研究依据见 [成长设计](progression-design.md)。

战役、影子和无尽都由 Meta 管理同一个暖晶钱包。关卡首通、提星与最多三次重复通关分别计奖；影子五阶首次最多合计 50，无尽前一百波最多合计 40。统计档案不再额外发旧版整章奖励。某角色完成全部五十关才能获得对应构筑全通记录；单关胜利不能冒充全程最快成绩。

## 影伴身份与切磋

`RunRecorder` 记录移动、开火、闪避、技能和受伤；`ShadowDirector` 根据净化后的档案推导速度、射程、节奏、同行 / 守营倾向与目标偏好。战术型优先远程、召唤和治疗，守营型关注营地近敌；掩体遮挡时不会隔墙输出。首局没有档案也有见习影伴“小暖”。

当前是**本机行为档案驱动的规则影子**，不是训练模型、逐帧回放、联网真人或自博弈学习。影伴最大理论持续单体输出预算不超过基础玩家 DPS 的 20%，价值主要来自覆盖另一条来路；实际影响仍待真人验证。

影子切磋成为独立模式，五阶分别为初次击掌、纸风车回旋、薄荷快步、花灯双人舞、昨日游园会。每阶三轮、可读预警；第四、第五阶同时面对两位影子。切磋记录与战役三星分别保存。

## 美术、反馈与持久化

本轮加入原创生成的水粉旅行主视觉、角色图集、地面图集。运行素材位于 [`src/public/art/`](../src/public/art/)；透明角色保留 PNG，主视觉 / 地面编码为 JPEG，对应生成原图保存在 [`art/source/`](../art/source/)。完整提示与用途见 [生成来源清单](art-generation-manifest.json)，方向研究与接入方式见 [绘本美术方向](art-direction-v2.md)。第三方游戏参考图片只用于研究，没有作为本项目素材发布。

菜单以留白插画和书页组织信息；选关采用旅途路线；工坊用邮戳与行囊展示装备、研究、专精；敌我与地形结合纹理、形状、轮廓和清晰预警。参考作品的具体场景或角色没有被直接复制。商业资产、名称与商标审阅仍是正式发行前的独立事项。

PC：WASD 移动、鼠标瞄准、左键射击、Shift / 右键闪避、Space 技能、Q 换技能、E 指挥影伴、Esc 暂停。设置支持音量、减少动态效果和持续射击。暂停、升级、教程及失焦时停止战斗计时；技能能量不足时给出可读提示。

Meta 内容升级为 v3，兼容旧版暖晶、工坊和解锁。旧已通章节映射成对应十个小关的一星访问记录，不追溯发首通奖励。关卡 / 站点起点续玩保存模式、角色、卡序、有效时长、得分与行为档案，重建开场，不保存瞬时物理世界。写入失败不会报告虚假的购买或奖励成功；未来版本存档不会被旧客户端覆盖。

`SessionMetricsManager` 只在本机记录最近 120 条已完成波次的模拟活跃战斗用时，汇总每章样本数、中位数和 p90；每帧计时增量有限制，因此不是墙钟时间。单波汇总不能代表独立关卡或完整路线实测时长，也不能把不同版本的旧样本当作新版平衡证据。

## 节奏假设与验证标准

`npm run analyze:pacing` 检查五十关理论敌人负载；多数关卡在“初步流派”假设下约为 **30–150 秒活跃战斗，另假设 20–40 秒读卡**。命中率、开火比例、技能贡献和读卡时间都属于模型假设，未由真人样本确认。详见 [新版节奏分析](campaign-pacing-v2.md)。旧四章整局分钟数不适用于新五十关，也不再把每关 2–4 分钟作为当前预算。

核心体验证据需要玩家能说出：哪里适合拦截、哪个敌人应先处理、影伴两种指令有何差别、当前构筑擅长什么，以及失败后下一次准备怎样改变。5 人观察和 15–30 人方向测试协议见 [市场与可玩性研究](market-and-playability-research.md)；旧研究里的四章结构和分钟数属于前一版历史假设。

完整 `release:web` 已通过：84 项自动测试、TypeScript、生产构建、静态检查与依赖审计（0 已知漏洞）；1.3.0-rc.1 静态候选目录已生成。隔离 Electron 44 / Chromium 152.0.7977.54 取得 12 张实际画面；原生 D 移动、E 指令、Space 能量提示、暂停和第五阶三轮影子结算通过。另一组加速场景检查完成五十关实际出生 / 伤害 / 卡牌 / 结算 / 存档，并验证无尽第二站保留工程师与七张升级卡，两组记录均无渲染器错误。

最终正式静态包也通过独立生产渲染检查：没有 `__sunlitQA` 调试入口，原生点击 / 按键完成首页→路线→编队→教程→选卡→战斗→暂停→回营→续玩，并取得九张截图，渲染器错误为空。源码保存了 [生产报告](qa/1.3.0-rc.1/production.json)、[首页截图](qa/1.3.0-rc.1/production-menu.png) 和 [战场截图](qa/1.3.0-rc.1/production-battle.png)。

这些检查使用隔离档案，其中全关卡和影子结算使用加速清怪，不读取用户浏览器数据，也不是正常玩家通关或用时测量。Chrome / Edge / Firefox 兼容、参考硬件性能与真人盲测尚未完成。最终证据及发布包集中在 [发行准备](release-readiness.md)，源码保存的 [验证摘要](validation-1.3.0-rc.1.json) 明确标出边界。
