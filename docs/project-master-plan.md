# 暖影同行 / Sunlit Echoes：项目总纲

更新：2026-09-12。阶段：PC 浏览器可试玩候选版迭代，完成状态以 [发行准备](release-readiness.md) 证据为准。技术包名仍为 `shadow-legion`，存储键保留向后兼容。

## 定位与设计约束

**借地形守住温暖营地，搭出自己的技能流派，让昨天的战斗习惯成为今天的影伴。**

玩家同时保护自己与营地，通过移动、瞄准、闪避、引走威胁和处理后排决定成败。影伴同行或守营，给玩家另一侧截击的窗口。地图、流派和影子共同改变“去哪里、先处理谁、何时回防、把谁留在家”。

用户要求温和、温暖、风趣且区别于末日暗黑风，因此统一采用纸张、花园、围巾、花瓣、爆米花、茶会与蜜蜂语言。温暖与操作挑战并存；危险区必须可读，营地失败必须能归因。

## 完整循环

```text
营地 / 工坊 / 设置
→ 伙伴 + 已解锁章节 + 可选镜像切磋
→ 地图来路与规则提示
→ 玩家截击 + 影伴同行/守营 + 旅途委托
→ 每波三选一改装，三次同流派专精进化
→ 第五波章节 Boss
→ 章节恢复、战利品、下一站解锁与章节起点存档
→ 四章成功或玩家/营地失败后结算
→ 保存暖晶和行为档案，下一局换打法或带新影伴倾向
```

首局没有档案也有见习影伴“小暖”；镜像切磋可关闭。影伴最大理论持续单体输出不超过基础玩家 DPS 的 20%，价值更多来自覆盖另一路而非代替玩家。实际贡献仍需真人验证。

## 地图与敌人

| 章 | 规则身份 | 主要决定 |
|---|---|---|
| 1 | 南北树径，古木挡双方子弹；第一波先教一个来路 | 读路线、挡弹、指挥影伴、闪避回防 |
| 2 | 东西来敌、暖砂减速 | 何时切远程后排、如何利用慢行地带 |
| 3 | 三桥与交替潮汐 | 提前换路，高速与召唤谁先处理 |
| 4 | 多街口混编，灯带先预警后爆发 | 借地形输出，拆解治疗/前排/远程协同 |

地形影响敌我，表现必须匹配实际区域。四章各五波，最后一波 Boss，不用强制空等凑局长。八类职责为基础数量、侧翼、远程、重甲、突进、召唤、爆破、治疗；可爱剪影仍要区分职责。

Boss 冲锋基线：预警 900ms，持续 650ms，伤害走廊宽 72，基础速度 440；预警长度等于实际速度×时长。Boss 不重复叠加精英生命倍率。各图公平性与数值强弱待正常游戏实测。

## 流派与成长

| 代码身份 | 打法 | 职业技能 |
|---|---|---|
| ranger / nova | 机动爆发、暴击与范围连锁 | 花火派对 |
| gunner / storm | 多弹道、连射、穿透，移速有代价 | 爆米花雨 |
| warden / rift | 生命、护盾、迟滞，射速有代价 | 慢悠悠茶会 |
| engineer / engineer | 追踪、弹射、部署，单发伤害有代价 | 蜜蜂小帮手 |

波间卡来自专精、通用辅助和已解锁支援技能；过滤重复、满层/满级和不合法前置。玩家满血但营地受损仍可获得急救。三次专精只触发一次进化，最早第一章出现，不把“第 2–3 章才成型”当作事实。章间大奖带入后续章节。

跨局优先扩展地图、伙伴和技能选择；工坊每项五级，最多伤害 +15%、生命 +25、开局能量 +40。旧档迁移按已有章节进度补齐解锁。战役奖励按本次起始章节后的累计波次计算；从第一章出发的首次全战役且新流派完成基准为 13 暖晶，新流派奖励只发一次。直接从第四章出发的胜利基准为 6 暖晶，不获得完整构筑首通与全程最快纪录；第一波失败不凭高章节编号获奖。排行榜支持四个流派，修复工程师读回丢失。

## 影子与旅途委托

`RunRecorder` 记录移动、开火、闪避、技能和受伤。`ShadowDirector` 净化档案并推导速度、射程、开火节奏、模式和目标偏好；战术型优先远程/召唤/治疗，守营型关注营地近敌，射线遇掩体不会隔墙输出。

当前是**本机行为档案驱动的规则影子**，不是训练模型、逐帧回放、在线好友或自博弈学习。可选切磋让玩家面对自己的行为倾向，形成无需服务器的可玩原型；文案不能承诺“进化 AI”或“真实玩家对战”。

每章三项委托：安排一次影伴、营地生命至少 60% 时完成三波、本章动作练习。第一章练闪避，后续章练地形利用；开启镜像后第三项换为完成切磋。奖励只领取一次，转为能量和营地恢复，支持当前战斗。

## 表现、控制与持久化

菜单、编队、工坊和结算共用纸张卡片与花园插画；战场暖地色、圆润角色、花火与小工具反馈。敌弹/友弹、危险/装饰必须依靠颜色和形状一起区分。当前程序绘制美术不等于完成真人审美、可访问性或最终音乐验收。

PC：WASD 移动、鼠标瞄准、左键射击、Shift/右键闪避、Space 技能、Q 换技能、E 指挥影伴、Esc 暂停。设置有音量、减少动态效果和持续射击；默认考虑系统动态偏好。计时需在升级、教程、暂停和失焦期间停止。

章节起点续玩保存流派卡序、有效时长、得分和累计行为，重建章节开场而非中途物理状态；非法存档被拒绝。`SessionMetricsManager` 仅在本机记录最近 120 个完成波次的净战斗时间、伙伴、切磋状态、营地血量。汇总明确显示样本数，单波中位数/p90 不能称为整章时长。

## 时长与发布判据

旧“四章 20–30 分钟”没有真实样本。`npm run analyze:pacing` 从代码重算敌人负载，其命中率/开火占比是假设而非玩家数据。暂以首章 3–5 分钟、首次成功巡游 12–20 分钟为待测目标，章节提供自然停点。

核心证据为：玩家理解双失败，主动利用地形，知道影伴两种指令差别，能说出流派身份，理解失败且愿意重开。来源与 5 人观察 / 15–30 人方向测试协议见 [研究](market-and-playability-research.md)。未完成人类样本就不报告留存、可玩性或商业验证通过。

`npm test` 覆盖真实纯逻辑，`npm run check` 额外构建并检查资产、开发入口泄露和体积，`npm run release:web` 再执行依赖审计并生成带许可证、部署说明和 SHA-256 清单的静态目录。无需购买服务器。历史 EXE 未在本轮更新，不是新版交付。

当前浏览器控制连接失败，真实视觉、兼容和性能验收仍未完成。所有证据及未完成门槛集中到 [发行准备](release-readiness.md)。

## 决策历史

- 2026-08：收敛为四章动作防线，突出主动移动、地图机制和兵种身份。
- 2026-08-27：影子只剩档案，旧总纲主动后置其玩法；旧验收只适用于当时 Demo。
- 2026-09-12：依用户要求统一暖色方向，将地形、流派、影伴、可选镜像与旅途目标串成循环；加入章节续玩、局长样本和发布门槛，明确规则影子与训练模型区别。

每个后续功能都必须改变至少一个真实决定：去哪里、先打谁、何时回防、如何与影子分工。
