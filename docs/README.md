# 项目文档入口

更新日期：2026-08-26

本目录只维护会直接指导当前产品决策的文档。代码实现与这里冲突时，以“第一阶段可玩切片”的现状表和实际代码为准，并在同一提交中修正文档。

## 阅读顺序

1. [第一阶段可玩切片](design/phase1-playable-slice.md)：当前游戏有什么、怎样验收、还缺什么。
2. [五阶段产品路线图](design/development-roadmap-v2.md)：何时做 AI、品质、微信和商业化。
3. [AI 战术导演方向](design/core-ai-gameplay-direction.md)：下一阶段唯一优先实验及其停止条件。
4. [市场与智能对手调研](research/market-and-ai-review-2026.md)：市场事实、研究证据和由此得到的产品判断。
5. [更新日志](changelog.md)：重要改动与历史转向摘要。

## 文档规则

- 只保留当前结论，不并排维护互相冲突的旧 GDD。
- 研究事实附来源；设计推论明确标注为判断，不伪装成市场事实。
- 每一阶段同时写“通过条件”和“停止条件”，避免以堆功能代替验证。
- 被淘汰的通道 RTS、参数化 Shadow 和 30 波旧方案已从活跃文档移除；需要追溯时使用 Git 历史。
