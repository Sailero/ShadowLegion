# 更新日志

## 2026-08-26 — 成长闭环与 AI 影子方向重审

### 第一阶段补完

- 三条协议各增加一次“超限进化”：累计三次同流派强化后产生明确能力跃迁和局内演出。
- 增加影核、三项有上限的军团工坊、协议首通奖励、跨局统计和最佳记录，形成轻量局外目标。
- 每局记录移动、射击、闪避、技能和承伤，结算生成火力/机动/反应/技巧四维影子档案。
- 菜单与结算接入工坊和影子档案；局外数值上限受控，避免成长替代操作和构筑。
- 运行时数据测试提升至 21 项，场景测试提升至 29 项。

### 核心方向调整

- 不取消自博弈，而是把它从首版玩家功能下沉为后期离线训练、发现反策略和维持策略多样性的工具。
- 核心卖点从“敌军按波弱针对玩家”升级为“每局塑造同一个影子人格：陪玩家割草、暴露玩家习惯、异步代表玩家挑战别人”。
- 战术导演保留为遭遇编排子系统，只制造可读变化与少量挑战岛，不持续硬克制玩家。
- 第二阶段改为依次验证个性化影子队友、影子入侵、好友异步挑战；未证明身份感前不建设云端模型或联机系统。
