## v1.0.2 — 怪物扩展 + 追踪弹重写 + 全面增强 (2026-08-17)

### 新增内容
- **忍者**：高速近战敌人，打了就跑的灵活 AI，自带闪避能力
- **召唤师**：远程散射 + 定期召唤弱化小怪的法师敌人
- **精英闪避**：精英蝙蝠/忍者检测 70px 内子弹弹道，智能侧向闪避（减伤 70%）
- **精英突进**：精英重甲/史莱姆在中距离触发高速冲锋
- **16 种新升级**：暴击、吸血、爆炸弹、弹射、冰冻、狂暴、荆棘、闪避、残影、重生等
- **技能解锁预览**：获取新技能时弹出交互动画展示
- **更强 Boss AI**：环形弹幕（8方向）、多段散射、环绕走位

### 重写
- **追踪弹系统**：基于二次方程拦截预测，瞄准敌人未来位置而非当前位置；追踪范围 120→300px；距离自适应转向率
- **hitlag 系统**：从 physics.timeScale 改为帧跳过（performance.now），彻底消除卡死

### 修复
- 受伤卡死（UI 始终渲染，死亡时暂停物理引擎）
- 无敌时间过长（400→250ms）
- XP 宝石性能问题（上限 60、8 秒过期）
- 子弹池无限增长（上限 200/100）
- 教程不显示（改用 Phaser.Registry）
- 所有回调 try-catch 防崩溃

### 测试
- RuntimeTest 新增：新怪物验证、新升级完整性、波次引用、英雄属性、UI 元素、碰撞检测
- scenarioTest 新增：XP 宝石上限、敌人数量、升级追踪、英雄状态有效性

## v1.0.0 — Shadow Legion Phase 1 (2026-08-13)

### 全面重构：俯视角动作生存游戏

彻底重构游戏架构，从通道制 RTS 转型为俯视角动作生存模式（类 Vampire Survivors + 几何战争）。

#### 核心系统
- **Hero.ts**: 完整英雄操控 — WASD 惯性移动、鼠标瞄准、左键自动射击、Shift 闪避翻滚(无敌帧+拖影)、Space 蓄力爆炸
- **Enemy.ts**: 4种敌人 + 精英 + Boss，各具独立 AI（追踪/变向/保距射箭/冲锋）
- **Projectile.ts**: 子弹系统含穿透弹、追踪弹、散射变体
- **WaveManager.ts**: 3关×10波渐进式波次生成，含 Boss 波
- **UpgradeManager.ts**: 15种波间升级 + 4种永久升级，3选1卡牌式 UI

#### 视觉 & 手感
- 程序化生成像素风精灵（SpriteFactory）：英雄、4种敌人、子弹、经验宝石、粒子
- 击中反馈：白闪(50ms) + 击退 + 粒子碎片 + 屏幕微震 + 浮动伤害数字
- 击杀反馈：粒子爆炸 + hitlag停顿 + 经验宝石掉落(磁吸收集)
- 闪避拖影、蓄力爆炸范围可视化、Boss 出场警告
- 平滑相机跟随(lerp 0.08)、HP/蓄力/闪避冷却 UI

#### 关卡与进度
- 3关30波完整流程，通关显示胜利画面
- 升级跨关卡持久化，关卡间全额回复 HP
- 分数 & 击杀统计，游戏结束/胜利结算屏

#### 架构预留（Phase 2）
- `Hero.getStateVector()`: 英雄状态特征向量（8维）
- `ArenaScene.allies[]`: 分身数组占位
- `BehaviorRecordingConfig` 接口定义

## v0.3.0-alpha (2026-08-13)

### 重大重构：从六边形回合制 → 实时战术攻防

完全重新设计游戏类型和核心机制，引入行为克隆驱动的策略学习系统。

#### 新增核心系统
- **行为学习系统**：玩家手动操控单位后，系统自动学习操作风格
  - `BehaviorRecorder`: 记录玩家操作时间序列
  - `ProfileExtractor`: 从操作中提取6个行为参数（进攻性、目标偏好、撤退阈值、迂回倾向、编队间距、响应延迟）
  - `ParametricAgent`: 参数化智能体，按学习到的参数自主行动
  - `StrategyStorage`: localStorage存储策略和进度
- **实时战斗场景**：横向通道制战场，支持自动战斗+手动接管切换
- **关卡系统**：10关主线战役，逐步解锁兵种和策略能力
- **策略卡片**：在战役地图中查看/重置已学习的行为参数

#### 新增内容
- 5种单位类型：轻步兵、重装兵、射手、坦克、侦察车
- 10关主线关卡（含教学引导）
- 关卡选择地图（含星级评价）
- 战斗UI（顶栏信息、部署按钮、释放控制按钮）

#### 动画系统
- 单位出生缩放动画
- 攻击闪烁效果
- 伤害数字飘字
- 单位死亡缩小消失
- 关卡开始横幅动画
- 行为学习反馈弹窗
- 命令指示环形动画

#### 技术变更
- 游戏类型：回合制六边形 → 实时通道制攻防
- 删除旧版六边形网格、回合管理、旧AI系统
- 新增 `behavior/` 模块（行为学习核心）
- 新增 `data/levels.ts`（关卡配置）
- 新增 `CampaignScene`（关卡选择）
- 重写 `BattleScene`（实时战斗）
- 重写 `MenuScene`（新版主菜单）
