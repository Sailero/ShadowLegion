# 版本变更日志

## [v0.1.0-alpha] - 2026-08-13

### 新增（Added）
- 项目初始化：搭建基础目录结构
- 技术栈选型：Phaser 3 + TypeScript + Vite
- 核心文档：市场调研报告、游戏设计文档（GDD）、技术架构文档
- 六边形网格系统（HexGrid）：Axial 坐标系、坐标转换、邻居查找、距离计算、可达范围 BFS
- 单位系统基础框架（Unit）：突击兵、盾卫兵、狙击手、侦察兵、工程兵
- 建筑系统基础框架（Building）：箭塔、城墙
- 游戏状态管理（GameState）：回合制流程、资源系统
- 回合管理器（TurnManager）：部署-行动-结算流程
- AI 系统基础框架：三种策略（进攻/防守/均衡）+ 策略选择器
- 场景系统：启动场景、主菜单、游戏场景、UI 覆盖层
- 可运行的 Demo：地图渲染、单位放置、基础交互

### 说明
- 这是项目的初始版本，包含核心框架和最小可玩 Demo
- AI 目前使用规则系统，后续将引入 RL 模型
- 美术使用程序化生成的几何图形，后续可替换为像素美术资源
