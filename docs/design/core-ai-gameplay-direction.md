# AI 核心方向：会观察、会布阵、能被反制的战术军团

> 状态：第二阶段唯一优先实验，不代表最终卖点已验证
>
> 前置条件：第一阶段外部盲测通过
>
> 更新日期：2026-08-26

## 1. 玩家真正购买的体验

技术命题是“多智能体对玩家策略进行有边界的自适应”；玩家听得懂的产品承诺是：

> **敌军会记住你上一波怎样战斗，下一波公开换一种协同阵型来对付你；你可以读懂、欺骗并拆掉它的计划。**

核心乐趣不是 AI 把玩家打败，而是双方产生连续的策略对话：

```text
我形成打法 → 敌军看懂一部分 → 它公开出招
→ 我识别弱点并反制 → 它保留记忆但不会完美克制
→ 结算让我看懂这段交锋
```

“会记仇的军团”比“模型使用了 MARL”更适合商店页、短视频和首局教学。

## 2. 为什么不以轨迹复制为主线

单纯回放玩家移动和射击，通常只是增加一个自动炮台：输出变高，但没有新决策，还容易让玩家困惑“我现在要配合谁、为什么要重复这条路线”。

轨迹分身只有同时存在以下结构才值得保留：

- 两个位置必须同时占领或攻击。
- 过去的攻击能与现在的攻击形成夹角、接力或组合反应。
- 玩家必须为未来分身规划路线，并为此牺牲当下最优输出。
- 分身会复现错误，玩家需要管理风险而不是白拿伤害。

当前 8 波生存框架没有这些空间目标，因此轨迹分身只作为后续独立实验，不承担近期核心卖点。

## 3. 为什么选择“战术导演”而非更强的个体 AI

现有游戏已经有追击、侧翼、远程、重甲、猎杀和召唤六种职责。试玩中，单个敌人的差别可读，但它们大多各自行动；最便宜且最容易被看见的提升，是让同一批单位共同执行一个计划。

战术导演只在波次间做高层选择，各单位仍使用稳定的本地控制器：

```text
PlayerModel（观察玩家）
       ↓
StrategyDirector（选择战术与强度预算）
       ↓
SquadBlackboard（共享目标、侧翼槽、集火对象和撤退状态）
       ↓
RoleController（坦克/远程/忍者等执行自己的职责）
       ↓
BattleReport（解释敌军为何出招、玩家如何破解）
```

这套结构客户端可运行、可测试、可回放，也能在以后把规则选择器替换为 bandit、策略池或离线学习模型。

## 4. 第一批三套战术

三套战术必须先以随机方式验证，本身不好玩就不能靠“自适应”拯救。

### 包抄阵

- 重甲从正面压缩空间，忍者占据左右侧翼槽，远程封锁惯常后撤方向。
- 玩家读法：地面显示两个侧翼箭头，忍者进场前有短暂标记。
- 反制：提前换向、穿过尚未闭合的一侧、优先击杀侧翼单位。
- 针对倾向：持续后退和固定方向风筝。

### 压制阵

- 两名远程占固定火力锚点，重甲做屏障，近战只负责把玩家赶出安全区。
- 玩家读法：火力锚点与射线预览清楚显示，远程单位带统一战术色。
- 反制：用闪避穿过火力线，先处理一个锚点，制造新的安全侧。
- 针对倾向：长时间站桩或依赖直线射击。

### 猎杀阵

- 普通单位制造噪声和碰撞压力，忍者等待玩家交出闪避后再延迟突进。
- 玩家读法：猎杀单位头顶显示“锁定”，突进必须有反应窗口。
- 反制：保留闪避、用控制技能打断、故意诱骗一次假窗口。
- 针对倾向：闪避一冷却就使用、低血仍激进贴近。

每套战术必须有一个明显弱点，且不能通过偷偷增加 HP、伤害或读取按键来实现。

## 5. 最小玩家画像

第一版只使用四组能直接映射到反制的统计，不采集高维原始轨迹：

| 特征 | 低成本计算 | 能影响什么 |
|---|---|---|
| 战斗距离 | 与最高威胁敌人的平均距离 | 包抄或近身压力倾向 |
| 移动模式 | 移动时间、方向变化、固定后撤方向 | 侧翼槽与火力锚点 |
| 闪避时机 | 冷却后多久使用、是否用于脱离红线 | 猎杀单位的等待窗口 |
| 目标/构筑 | 首次命中与击杀职责、当前协议 | 单位比例和战术候选，不直接改属性 |

画像只使用最近 1–2 波并做平滑，允许玩家主动伪装。故意在观察波改变打法、诱导敌军出错，本身可以成为高阶乐趣。

## 6. 选择器必须有边界

初版使用可解释评分即可：

```text
strategyScore = 0.45 × weakCounter
              + 0.35 × novelty
              + 0.20 × neutralFit
              - repetitionPenalty
```

- `weakCounter` 只提供轻度针对，不选择完美硬克制。
- `novelty` 确保玩家不会连续面对同一解法。
- `neutralFit` 保证战术与当前波单位和空间匹配。
- 同一战术最多连续出现一次。
- 每次选择保存原因和确定性种子，能重放和调试。

当规则版本通过后，可用 contextual bandit 更新权重；奖励应混合“玩家是否改变策略、是否认为公平、是否愿意再玩”，不能只最大化伤害或失败率。

## 7. 让玩家看见 AI

### 战前 2 秒

```text
敌军分析：你连续向右后撤
战术调整：包抄阵
破局提示：侧翼闭合前击破一端
```

### 战斗中

- 相同战术使用统一颜色、阵型线和指挥标记。
- 高影响协同必须预警，不能在屏幕外瞬时完成。
- 玩家拆掉关键单位时明确提示“侧翼失效”或“火力网瓦解”。

### 波后 1 张卡

- 敌军观察了什么。
- 选择了什么战术。
- 该战术是否奏效。
- 玩家做了哪项有效反制。

解释必须短；如果玩家需要阅读技术报告才能理解，说明行为设计本身失败。

## 8. A/B/C 实验

使用相同敌人、数值和波次预算，只更换策略选择方式：

- A 固定：预设顺序，验证基础战术教学。
- B 随机：从有效策略池随机抽取，验证多样性本身。
- C 自适应：读取玩家画像，按有边界规则选择。

### 核心指标

- 不看说明时，能否说出敌军使用了什么策略。
- 玩家是否改变走位、闪避时机或目标优先级。
- 失败是否公平，能否提出下次反制方案。
- C 相比 B 是否提高主观乐趣、重开意愿和会话局数。
- C 是否减少构筑多样性；如果玩家因怕被针对而不敢成型，这是负面结果。

### 通过标准

- ≥ 70% 玩家能描述至少两种敌军战术。
- ≥ 60% 玩家在第二次回应后主动改变一种行为。
- C 组相较 B 组的重开意愿和“对手像在思考”评分均有稳定提升。
- C 组公平感不低于 B 组，首局理解成本没有显著增加。

若 C 不优于 B，就保留好玩的随机策略库，停止投入玩家建模；这也是一个成功的低成本结论。

## 9. 实施切片

1. 把敌人高层意图从 `Enemy` 中抽出，增加角色槽和小队黑板。
2. 用现有 6 种敌人实现三套静态战术，不增加新美术和新敌种。
3. 为每套战术加入战前提示、战术色、瓦解反馈和波后卡。
4. 增加本地遥测与确定性种子，完成 A/B 测试。
5. 实现四组玩家特征和规则选择器，加入 C 组。
6. 通过实验后再讨论跨局记忆、好友 Ghost 或离线自博弈。

## 10. 明确停止条件

出现以下任一现象并经两轮修改仍无改善，应降级该方向：

- 玩家只感到敌人变多或变强，看不到协同。
- 玩家发现一个通用解法，可以忽略所有战术。
- 自适应压制了构筑成型和清场爽感。
- 解释 UI 比战斗更复杂。
- 随机战术与自适应战术没有体验差异。
- 为维持效果必须在云端逐帧推理，破坏小游戏成本、延迟或离线能力。
