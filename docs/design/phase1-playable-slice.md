# 第一阶段可玩切片

> 状态：功能与本地验收完成，等待外部盲测通过产品门槛
>
> 基线日期：2026-08-26

## 1. 本阶段回答什么

第一阶段只回答一个问题：**即使不宣传 AI，当前战斗是否足以让玩家完成一局，并愿意尝试另一条构筑？**

本阶段不是正式发行版，也不以内容总量为目标。旧版 3 关 30 波和 30 余项升级被收缩为一条更短、更容易平衡的完整流程。

## 2. 当前可玩闭环

```text
单屏教学
→ 第 1 波熟悉移动、射击、闪避和充能技能
→ 三选一确定爆裂 / 弹幕 / 时隙协议
→ 每波引入一种新威胁和一次流派改装
→ 第 7 波混编压力测试
→ 第 8 波军团核心 Boss
→ 胜利/失败结算、记录分数/击杀/时间/构筑
→ 快速重开或进入无尽演练
```

### 战斗内容

| 模块 | 当前实现 | 设计作用 |
|---|---|---|
| 基础操作 | WASD、鼠标按住射击、Shift 闪避、Space 技能 | 保留走位、瞄准、风险和资源时机 |
| 波次 | 单局 8 波，命名与战术提示 | 控制节奏，保证一局有开始、升级、高潮和结尾 |
| 构筑 | 爆裂、弹幕、时隙 3 条协议 | 分别强调范围暴击、持续多弹道、控制生存 |
| 选择结构 | 协议确定后，通常出现 2 张流派牌 + 1 张通用牌 | 兼顾成型感与临场生存选择 |
| 敌人 | 追击、侧翼、远程、重甲、猎杀、召唤 6 种职责 | 迫使玩家改变移动和目标优先级 |
| Boss | 独立血条、召唤、弹幕、带红线预警的冲锋 | 检验构筑，同时保证危险可以归因 |
| 反馈 | 受击闪白、击退、数字、粒子、震动、音效、准星 | 提高清晰度和击杀爽感 |
| 流程 | 教程、暂停、胜负结算、排行榜、重开、菜单 | 让 Demo 可交给不了解项目的人独立试玩 |

## 3. 三条构筑的体验承诺

### 爆裂协议

- 开局立刻获得命中爆炸和更高等级能量爆发。
- 后续通过暴击、爆炸强化和技能升级形成范围连锁。
- 爽点：少量关键命中引发成片清场。

### 弹幕协议

- 开局获得双弹道和弹幕风暴。
- 后续通过并联枪管、穿透和攻速持续扩大火力覆盖。
- 爽点：从精确射击逐步成长为稳定火力网。

### 时隙协议

- 开局获得时空裂隙和护盾。
- 后续通过减速、护盾、闪避冷却形成控场与机动循环。
- 爽点：在高压弹幕中主动制造安全窗口。

构筑通过的判断不是最终 DPS 接近，而是盲测玩家能从画面和操作中说出三者差异。

## 4. 已完成的工程验收

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 生产 JS 约 1.58 MB，gzip 约 369 KB；目前尚未加入正式美术和音频资源。
- 浏览器数据测试 16/16、场景测试 27/27。
- 浏览器无 console error / warning。
- 人工走查了菜单、教程、射击/闪避、三选一、三条流派卡池、波次提示、Boss 血条和冲锋预警、暂停、胜利结算与重开。
- 修正了 Boss 出场后立即攻击的问题：其攻击计时从出生时开始，首个预警不会与登场提示同时触发。

## 5. 尚未被证明的部分

“功能可玩”不等于“市场上好玩”。以下内容必须由非开发者验证：

- 真实一局时长、前半局是否拖沓、Boss 数值是否合理。
- 射击、闪避和技能是否在没有解释时也足够清楚。
- 三条构筑是否都能成型，是否存在明显唯一最优解。
- 玩家死亡是否能归因，红线和远程弹道是否有足够反应时间。
- 结束后是否真有尝试另一协议的欲望。
- 当前程序化图形和音效是否已达到“可接受原型”，而不是被误认为最终品质。

微信触控、真机性能、平台生命周期、正式美术、局外成长、商业化和联网均不属于第一阶段完成项。

## 6. 盲测方案与门槛

先做 5 人问题发现，再做 10–20 人方向验收。测试者不提前阅读设计文档，也不告知未来 AI 卖点。

### 自动记录

- 是否完成教程、到达波次、胜负、用时、击杀、协议。
- 后续补充：死亡来源、每次升级选择、技能使用次数、闪避次数。

### 目标门槛

| 指标 | 第一轮目标 |
|---|---:|
| 独立完成教学并正确说出四个操作 | ≥ 80% |
| 第 2 波前退出 | < 15% |
| 首局到达 Boss | ≥ 50% |
| 首局通关率 | 25%–45% |
| 能说出至少两条构筑的差异 | ≥ 70% |
| 主要死亡原因可正确复述 | ≥ 80% |
| 结算后愿意立刻换协议再玩 | ≥ 50% |

通关率只是难度信号，不是唯一目标。若通关率合适但重开意愿低，仍判定基础循环未通过。

### 只问五个问题

1. 哪一刻最爽，哪一刻最无聊？
2. 你为什么死，下一次会怎样处理？
3. 你选了什么协议，它具体改变了什么？
4. 如果马上再开一局，你会换什么，为什么？
5. 你是否愿意再玩？0–10 分，低于 7 的原因是什么？

## 7. 进入第二阶段的决定

- 达到门槛：冻结基础规则，只修平衡和明显体验问题，开始 AI 战术导演 A/B/C 原型。
- 接近门槛：最多做两轮定向修改，优先修首波节奏、死亡可读性和构筑质变。
- 明显未达标：不开发学习型 AI；先决定是改善射击手感、改为自动瞄准，还是更换基础战斗框架。
