# 小游戏市场调研报告

> 调研时间：2026年8月  
> 调研范围：微信/抖音小游戏平台，全球休闲策略游戏市场

---

## 一、市场概况

### 1.1 整体市场规模

- 移动塔防/策略游戏市场 2025 年估值 **47 亿美元**，预计 2034 年达到 **102 亿美元**（CAGR 9.0%）
- 多人对战子品类增速最快（CAGR 11.4%），占市场 36.6%
- 混合休闲（Hybrid-Casual）是 2026 年唯一增长的休闲游戏细分市场，IAP 收入同比增长 **20%**，达到 **42 亿美元**

### 1.2 微信/抖音小游戏平台趋势

| 趋势 | 说明 | 代表产品 |
|------|------|---------|
| 玩法融合 | 模拟经营 + 实时攻防、自走棋 + 卡牌 | 《占城大师》《王者之弈》 |
| 策略轻量化 | 降低门槛但保留策略深度，"策略轻量化 ≠ 去策略化" | 《王者之弈》 |
| 随机性 + 策略性 | 盲盒地块、随机卡池提升复玩性 | 《占城大师》 |
| 肉鸽元素融合 | Roguelike + 塔防/策略 | 《我的防线》《向僵尸开炮》 |
| 短对局节奏 | 3-5 分钟完成一局，碎片化时间友好 | 主流趋势 |

## 二、竞品分析

### 2.1 《占城大师》— 轻量化 RTS

- **核心玩法**：1v1 实时对抗，六边形地图，卡牌 + RTS 融合
- **亮点**：随机地图生成、盲盒式建筑部署、"实时反馈 + 延时判定"的策略深度
- **商业化**：卡牌养成（局外付费）+ 短时对战娱乐（局内体验）
- **成绩**：抖音畅销榜 TOP3，微信畅销榜 TOP10
- **启示**：将硬核 RTS 休闲化改造，精准匹配碎片化需求

### 2.2 《王者之弈》— 轻量化自走棋

- **核心玩法**：自走棋 + 卡牌融合，轻量化策略设计
- **亮点**：保留策略深度的同时降低门槛，"碎片化娱乐 + 策略爽感"的平衡
- **成绩**：微信小游戏畅销榜 TOP25，抖音畅销榜 TOP18
- **启示**：过度简化、缺乏策略深度的产品几乎失去突围机会

### 2.3 《我的防线》— 硬核肉鸽塔防

- **核心玩法**：肉鸽 + 塔防，有限资源下的管理博弈
- **亮点**：体系化数值设计（DPS vs AOE），20级上限的精准资源分配
- **启示**：硬核数值策略 + 独特包装（电音震动反馈）可以从红海突围

### 2.4 国际竞品参考

| 游戏 | 玩法 | 借鉴点 |
|------|------|--------|
| Clash Royale | 实时卡牌对战 | 经典 1v1 攻防框架 |
| Slay the Spire | Roguelike + 卡牌构筑 | 策略深度 + 随机性 |
| Bloons TD 6 | 塔防 + 无尽模式 | 合作 + 长线运营 |
| Squad Busters | 多角色交叉对战 | IP 融合 + 轻量策略 |

## 三、技术趋势

### 3.1 开发框架

- **Phaser.js 4**：主流 HTML5 游戏框架，支持 Canvas/WebGL，成熟生态
- **TypeScript + Vite**：类型安全 + 快速构建，策略游戏首选技术栈
- **六边形网格**：策略游戏标准地图系统（参考 RedBlobGames 算法）

### 3.2 AI 技术

- **强化学习动态难度调整（DDA）**：通过训练不同技能水平的 AI 代理实现自适应对手
- **模仿学习 + RL 的个性化对手**：先模仿玩家行为，再训练对抗型 AI
- **混合系统**：规则系统保底 + ML 层个性化，当前工业界标准

## 四、市场机会与空白

### 4.1 已被充分覆盖

- 纯塔防（红海）
- 简单自走棋（同质化严重）
- 纯 IAA 广告变现休闲游戏

### 4.2 差异化机会

1. **AI 自适应对手**：当前小游戏市场几乎没有真正的 AI 自适应对手，绝大多数使用规则系统
2. **策略多样性奖励**：鼓励玩家尝试多种策略而非找到唯一最优解（反 "solved meta"）
3. **攻防不对称设计**：真正的非对称玩法（进攻方和防守方体验完全不同）
4. **"学术级"策略深度**：将博弈论概念（纳什均衡、混合策略、最大最小）融入可感知的游戏机制
5. **泛化挑战**：程序化生成的关卡迫使玩家适应新情境，而非记忆固定解法

---

## 五、结论

当前市场的核心矛盾是：**玩家渴望策略深度，但不接受操作复杂度**。成功产品的共同点是"策略轻量化"——保留决策深度但简化操作流程。结合强化学习和博弈论的学术背景，最大的差异化机会在于打造一个"每局都不同、对手会进化、策略多样性被奖励"的攻防博弈游戏。
