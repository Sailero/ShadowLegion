## 一、核心概念

### 1.1 一句话描述

> 一款融合博弈论与强化学习的六边形攻防策略小游戏，AI 对手会学习你的策略并进化，迫使你不断创新。

### 1.2 核心体验

- **"每局都是新挑战"**：程序化生成地图 + 自适应 AI，消除固定最优解
- **"策略多样性被奖励"**：使用更多元化的策略组合获得更高评价和奖励
- **"攻守转换的博弈快感"**：攻防角色可切换，策略逻辑完全不同

### 1.3 目标用户

- 喜欢策略游戏但没时间玩大型 SLG 的碎片化用户
- 对 AI 和博弈有好奇心的学生/职场人群
- 追求"赢在策略而非氪金"的竞技型玩家

## 二、游戏机制

### 2.1 地图系统

- **六边形网格**：10×10 的六边形地图（可扩展）
- **地形类型**：
  - 🟩 平原（标准移动/建造）
  - 🟫 高地（防御加成 +30%）
  - 🌊 水域（不可通行，可用桥梁建筑跨越）
  - 🌲 森林（隐蔽，进入需要额外行动点）
  - ⛏️ 资源点（产出额外资源）
- **迷雾系统**：部分区域被迷雾覆盖，需要侦察单位探索

### 2.2 资源系统

| 资源 | 获取方式 | 用途 |
|------|---------|------|
| 能量（Energy） | 每回合自动回复 + 资源点 | 部署单位、建造建筑 |
| 科技点（Tech） | 击败敌方单位 + 完成目标 | 解锁高级单位/策略 |
| 情报值（Intel） | 侦察行为 + 间谍建筑 | 揭示敌方部署、预测 AI 行为 |

### 2.3 单位系统

采用**三角克制**关系（受博弈论"石头剪刀布"扩展启发）：

```
        突击兵 (Striker)
       /          \
      克制        被克制
     /              \
  狙击手 ←—克制—— 盾卫兵
 (Sniper)        (Guardian)
```

| 单位 | 攻击 | 防御 | 移动 | 特殊能力 | 费用 |
|------|------|------|------|---------|------|
| 突击兵 | ★★★ | ★☆☆ | ★★★ | 冲锋（首次攻击伤害 ×1.5） | 3 能量 |
| 盾卫兵 | ★☆☆ | ★★★ | ★★☆ | 嘲讽（吸引周围敌方攻击） | 4 能量 |
| 狙击手 | ★★★★ | ★☆☆ | ★☆☆ | 远程（攻击范围 3 格） | 5 能量 |
| 侦察兵 | ★★☆ | ★☆☆ | ★★★★ | 揭示迷雾（3 格范围） | 2 能量 |
| 工程兵 | ★☆☆ | ★★☆ | ★★☆ | 建造/修复建筑 | 3 能量 |

### 2.4 建筑系统

| 建筑 | 功能 | 费用 |
|------|------|------|
| 箭塔 | 自动攻击范围内敌人 | 5 能量 |
| 城墙 | 阻挡移动，提供掩护 | 2 能量 |
| 兵营 | 减少该区域单位部署费用 | 6 能量 |
| 瞭望台 | 持续揭示大范围迷雾 | 4 能量 |
| 资源塔 | 提高能量回复速率 | 5 能量 |

### 2.5 回合制流程

```
每回合流程：
┌─────────────┐
│  资源结算    │ → 回复能量、科技点、情报值
├─────────────┤
│  部署阶段    │ → 部署新单位、建造新建筑
├─────────────┤
│  行动阶段    │ → 移动单位、发起攻击、使用技能
├─────────────┤
│  AI 回合     │ → AI 根据当前策略执行操作
├─────────────┤
│  结算阶段    │ → 计算战斗结果、检查胜负条件
└─────────────┘
```

### 2.6 胜负条件

- **歼灭胜利**：消灭敌方所有单位和建筑
- **占领胜利**：控制地图上 ≥70% 的资源点持续 3 回合
- **积分胜利**：20 回合后比较总积分（单位存活 + 资源控制 + 策略多样性加分）

## 三、核心差异化：学术融合设计

### 3.1 自适应 AI 系统（强化学习）

**设计原则**：AI 不是固定的脚本对手，而是一个会"学习"的对手。

```
玩家行为观察 → 特征提取 → 策略识别 → 反制策略生成
     ↑                                      ↓
     └──────── 对局结果反馈 ←───────────────┘
```

- **多级 AI 代理池**：预训练不同难度等级的 AI 代理，根据玩家水平动态切换
- **在线适应**：AI 在对局过程中实时调整策略权重
- **策略档案**：记录玩家历史策略偏好，AI 针对性地选择反制策略

### 3.2 策略多样性奖励（多样化策略）

**设计原则**：打破"唯一最优解"，让每种策略都有存在空间。

- **策略指纹系统**：追踪玩家使用的策略维度（进攻/防守/经济/侦察比例）
- **多样性分数**：使用策略的种类越多、组合越新颖，获得的奖励越高
- **反 Meta 机制**：如果某个策略使用率过高，AI 会自动学会针对性反制

### 3.3 攻防博弈机制

**设计原则**：攻击和防守不是简单的数值对抗，而是信息不完全博弈。

- **迷雾与侦察**：玩家无法完全掌握对手部署，需要在侦察投入和战斗力之间权衡
- **混合策略均衡**：部分战斗结果引入概率元素（如暴击率取决于策略组合的均衡程度）
- **承诺机制（Commitment）**：建筑一旦建造不可移动，迫使玩家提前做出战略承诺

### 3.4 泛化性能挑战

**设计原则**：好的策略应该在多种情境下都有效，而非只针对特定场景。

- **程序化地图生成**：每局地图随机生成，地形分布不同
- **变异规则**：特殊对局引入规则变体（如"资源减半"、"迷雾加深"、"禁用特定单位"）
- **泛化评分**：评估玩家策略在不同地图/规则下的表现稳定性

## 四、游戏模式

### 4.1 单人模式

- **战役模式**：逐步解锁单位和建筑的教学战役（10关）
- **挑战模式**：随机地图 + 随机规则变体的无尽挑战
- **AI 训练场**：观察 AI 对战，学习策略组合

### 4.2 多人模式（后期规划）

- **1v1 排位**：匹配同级别玩家进行对战
- **2v2 合作**：与队友配合的协作攻防
- **自定义对战**：自选地图、规则和 AI 难度

---

## 五、美术风格

- **像素风 + 等距视角**：低成本高辨识度，符合小游戏定位
- **配色方案**：暗色背景 + 高饱和度单位颜色（蓝方 vs 红方）
- **UI 风格**：简洁现代，扁平化设计，清晰的信息层级
